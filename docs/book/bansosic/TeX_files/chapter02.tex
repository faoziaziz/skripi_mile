\chapter{Toolkit}
Kita tahu bahwa untuk menempa sebuah pedang kita perlu untuk membuat sebuah palu, sebuah calderon untuk memasak api. Sepertihalnya dengan mendesain IC, kita perlu untuk membuat sebuah toolkit untuk mendesainnya. Namun berkat produk asing juga kita bisa menggunakan toolkit itu secara gratis. 

Toolkit yang akan kita gunakan jelas adalah verilog, simulator verilog, yosys, pdk130nm, serta openroad.
